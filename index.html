    Engle–Granger pairs, walk-forward

    The data is a synthetic cointegrated pair. Every quarter the model re-estimates the OLS hedge ratio on the trailing year and runs an ADF test on the residual, then trades the next quarter out of sample, but only if the pair passes at 5%. The rules match the repo: enter at |z| ≥ threshold, exit when z crosses 0, 20-day rolling z-score, and costs charged per unit change in position. One deliberate difference: the z-score uses the trailing 20 days across window boundaries, so the first days of each test window can trade.
